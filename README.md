# Min vinbok

En mobilvennlig, privat vindagbok. «Mine viner» viser bare viner som registreres enkeltvis. Viner som legges til under «Reiser», holdes på den aktuelle reisen. Appen bruker samme IndexedDB-database (`vinskap-db`) som tidligere versjoner.

Last opp alle filene i rotmappen til GitHub. API-mappen og miljøvariabelen for Vinmonopolet trengs ikke lenger.
